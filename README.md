# 하루 단어

Day01–10 영어 단어 학습 사이트. 각 Day 20개, 총 200개 단어 및 표현을 제공한 사진 10장과 직접 대조했습니다. 사진 원본은 저장소에 포함하지 않습니다.

- 단어 및 뜻 목록, 미국 영어 Samantha 음성 파일 200개
- 플래시카드: 뜻 확인 후 O/X 자기 평가, 다음 카드
- 객관식: 영어→한글 또는 한글→영어, 중복 없는 4개 선택지, 즉시 피드백
- 오답만 재학습, 전체 재학습, 중간 학습 자동 저장 및 이어하기
- 날짜별 완료 학습 횟수, 점수, 개별 오답, 누적 오답 순위
- 기기 브라우저 localStorage 저장, JSON 백업 및 중복 없는 복원
- 모바일·태블릿·PC 반응형, 키보드 포커스 및 버튼 접근성

## 실행

```sh
python3 -m http.server 8765
```

http://localhost:8765 접속. `qa/harness.cjs`는 Playwright 브라우저 하네스이며, 환경의 Playwright와 Chrome 경로에 맞춰 실행합니다. 테스트 데이터는 브라우저 격리 컨텍스트에만 저장됩니다.

## 저장과 점수

기록은 완료한 학습당 한 건씩 저장됩니다. 플래시카드 점수는 O/X 자기 평가, 객관식 점수는 자동 채점입니다. 오답 복습도 별도 학습 횟수로 계산하며, 누적 오답 횟수는 전체 완료 학습 기준입니다. 기기 간 자동 동기화는 제공하지 않으며 백업 파일 복원으로 옮길 수 있습니다. 사이트 데이터 삭제 시 백업하지 않은 기록이 사라집니다.

## 듣기

각 단어는 고정된 미국 영어 음성 파일을 재생합니다. 선택적 표현은 실제로 읽을 수 있도록 정리합니다(come[be] from → come from / be from, be going to-v → be going to). 파일 재생 실패 시 영어로 확인된 브라우저 음성으로만 대체합니다. 브라우저에 영어 음성이 없으면 알림을 표시합니다.

## 공개 배포

GitHub Actions가 정적 파일과 audio만 GitHub Pages에 배포합니다. 로그인 없이 공개 접속할 수 있습니다. 서버, 유료 API 및 외부 데이터베이스를 사용하지 않습니다.
