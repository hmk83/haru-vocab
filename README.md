# 현하늘의 영어 단어

Day01–50 영어 단어 학습 사이트. 각 Day 20개, 총 1,000개 단어 및 표현을 제공한 사진 50장과 직접 대조했습니다. 사진 원본은 저장소에 포함하지 않습니다.

- 단어 및 뜻 목록, 미국 영어 Samantha 음성 파일 1,000개
- 플래시카드: 영어/한글 문항 선택, 해석 확인 후 O/X 자기 평가
- 객관식: 영어→한글 또는 한글→영어, 중복 없는 4개 선택지, 모달 정답 확인
- 모든 새 학습/재학습 문항 셔플, 학습 이력이 있으면 언어 및 전체/오답 범위 선택
- 오답만 재학습, 전체 재학습, 중간 학습 자동 저장 및 이어하기
- 점수별 응원 메시지, 100점 완료 시 축하 효과
- 날짜별 완료 학습 횟수, 점수, 개별 오답, 누적 오답 순위
- 학습 결과 및 듣기 속도 자동 저장 (기기 브라우저 localStorage)
- 모바일·태블릿·PC 반응형, 키보드 포커스 및 버튼 접근성

## 실행

```sh
python3 -m http.server 8765
```

http://localhost:8765 접속. `qa/review-harness.cjs`는 Playwright 브라우저 하네스이며, 환경의 Playwright와 Chrome 경로에 맞춰 실행합니다. 테스트 데이터는 브라우저 격리 컨텍스트에만 저장됩니다.

## 저장과 점수

기록은 완료한 학습당 한 건씩 저장됩니다. 플래시카드 점수는 O/X 자기 평가, 객관식 점수는 자동 채점입니다. 오답 복습도 별도 학습 횟수로 계산하며, 누적 오답 횟수는 전체 완료 학습 기준입니다. 기기 간 자동 동기화는 제공하지 않습니다. 기존 기록 저장 키를 유지해 이번 업데이트 후에도 기록이 남습니다.

## 듣기

각 단어는 고정된 미국 영어 음성 파일을 재생합니다. 설정에서 듣기 속도를 0.6×~1.4×로 조절할 수 있으며 자동 저장됩니다. 선택적 표현은 실제로 읽을 수 있도록 정리합니다(come[be] from → come from / be from, be going to-v → be going to). 파일 재생 실패 시 영어로 확인된 브라우저 음성으로만 대체합니다. 브라우저에 영어 음성이 없으면 알림을 표시합니다.

## 공개 배포

GitHub Actions가 정적 파일과 audio만 GitHub Pages에 배포합니다. 로그인 없이 공개 접속할 수 있습니다. 서버, 유료 API 및 외부 데이터베이스를 사용하지 않습니다.

## 참고

단어장·카드 분류 흐름: [원보카](https://play.google.com/store/apps/details?id=com.zak1ller.Onevoca), [Quizlet Flashcards](https://help.quizlet.com/hc/en-ca/articles/360030988091-Studying-with-Flashcards). 본 사이트의 화면과 코드는 별도로 구현했습니다.

오답 범위는 같은 Day에서 각 단어의 가장 최근 완료 학습 응답을 기준으로 합니다. 플래시카드/객관식이 이 오답 목록을 공유하며, 복습에서 맞힌 단어는 다음 오답 학습에서 제외됩니다. PC·태블릿에서는 문항 영역이 화면 높이를 채우고 답변 버튼은 하단에 배치됩니다.

## 단어별 테두리

문항 박스의 5px 테두리는 단어별 누적 학습 단계(-5~+5)를 나타냅니다. 초기 0은 흰색, 정답마다 +1, 오답마다 -1이며 상하한에 도달하면 유지됩니다. 음수는 노랑→주황→빨강(-5), 양수는 연한 초록→진한 초록(+5)입니다. +5에서도 오답이면 +4로 내려갑니다. 같은 단어의 플래시카드·객관식·문항 언어에서 단계를 공유하며, 답변 즉시 기기에 저장합니다. 기존 완료 기록과 진행 중 초안을 한 번 반영합니다. `qa/proficiency-harness.cjs`가 경계값, 회복, 강등, 저장 유지 및 기존 기록 변환을 검증합니다.

## 테스트·주관식·학습 기록

햄버거 메뉴의 테스트에서 Day를 여러 개 선택하고 문제 방식과 문항 언어를 선택합니다. 30문항을 랜덤 출제하며, Day 하나만 선택하면 20개 단어가 일부 반복됩니다. 주관식은 반대 언어를 직접 입력하고 자동 채점합니다. 사전에 표시된 동의어와 괄호 표현을 허용하고 대소문자·공백·문장부호를 정규화합니다. 임의의 번역 동의어나 오타를 추측해 인정하지 않습니다.

단어장 첫 카드에서 전체 완료 기록의 누적 오답 단어를 모아 세 가지 방식으로 학습할 수 있습니다. 테스트와 오답 단어 학습도 완료 시 점수·문항·답변·유형을 저장합니다. 가장 최근 응답 기준의 오답 범위는 모든 문제 방식과 테스트에서 공유합니다.

학습 기록은 주간(월요일 시작), 월간, 연간 기간으로 필터링하고 이전·다음·오늘 버튼으로 이동합니다. 통계는 선택 기간 기준이며 결과 카드를 누르면 상세 결과를 확인합니다. 기존 저장 키와 이전 기록을 유지합니다.

검증: qa/review-harness.cjs, qa/proficiency-harness.cjs, qa/written-harness.cjs, qa/test-history-harness.cjs, qa/expansion-harness.cjs. 375×640 및 375×812 아이폰 12미니 화면 크기, 768×1024 및 1024×768 태블릿 화면 크기에서 반응형 동작을 확인합니다. 실제 iPhone 기기 검증과 구분되는 브라우저 자동화 검사입니다.
